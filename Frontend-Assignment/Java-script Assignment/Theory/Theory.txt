1. JavaScript Introduction 

    Question 1: What is JavaScript? Explain the role of JavaScript in web development. 
    What is JavaScript?

            JavaScript is a high-level, interpreted programming language mainly used to create interactive and dynamic websites. It is one of the core technologies of the web, along with:

            HTML — structures web content
            CSS — styles web pages
            JavaScript — adds behavior and interactivity

            JavaScript was originally developed to run inside web browsers, but today it is also used for:

            Server-side development
            Mobile applications
            Desktop applications
            Game development
            APIs and backend services
            Role of JavaScript in Web Development

            JavaScript plays a major role in making websites interactive, responsive, and user-friendly.

            1. Adds Interactivity

            JavaScript allows users to interact with web pages dynamically.

            Examples:

            Button click actions
            Dropdown menus
            Image sliders
            Pop-up windows
            Form validation

            Example:

            document.getElementById("btn").onclick = function() {
                alert("Button clicked!");
            };
            2. Manipulates Web Page Content

            JavaScript can change HTML and CSS content without reloading the page.

            Examples:

            Updating text
            Changing colors/styles
            Showing or hiding elements

            This is done using the DOM (Document Object Model).

            3. Creates Dynamic Web Applications

            Modern web applications rely heavily on JavaScript.

            Examples:

            Social media platforms
            Online shopping websites
            Video streaming sites
            Real-time chat applications

            Popular JavaScript frameworks/libraries include:

            React
            Angular
            Vue.js
            4. Handles Client-Side Validation

            JavaScript checks user input before sending data to the server.

            Examples:

            Validating email format
            Checking password length
            Preventing empty form submission

            Benefits:

            Faster feedback
            Reduced server load
            Better user experience
            5. Supports Asynchronous Communication

            JavaScript can communicate with servers in the background using:

            AJAX
            Fetch API

            This allows pages to update data without full page reloads.

            Example:

            Loading new messages in chat apps
            Refreshing notifications automatically
            6. Enables Server-Side Development

            Using Node.js, JavaScript can also run on servers.

            This allows developers to use one language for both:

            Frontend development
            Backend development

    Question 3: Discuss the use of <script> tag in HTML. How can you link an external JavaScript file to an HTML document? 
    Use of the <script> Tag in HTML

            The <script> tag in HTML is used to include or embed JavaScript code inside a web page. It allows web pages to become interactive and dynamic.

            JavaScript code can be:

            Written directly inside the HTML document (internal JavaScript)
            Linked from an external JavaScript file
            1. Using Internal JavaScript

            JavaScript code can be written between opening and closing <script> tags.

            Example:
            <!DOCTYPE html>
            <html>
            <head>
                <title>Internal JavaScript</title>
            </head>
            <body>

            <h1>Hello World</h1>

            <script>
                alert("Welcome to JavaScript!");
            </script>

            </body>
            </html>
            Explanation
            The browser reads the <script> tag.
            The JavaScript code inside it is executed.
            alert() displays a popup message.
            2. Purpose of the <script> Tag

            The <script> tag is used for:

            Adding interactivity
            Form validation
            Manipulating HTML and CSS
            Creating animations
            Handling events
            Communicating with servers
            3. Linking an External JavaScript File

            Instead of writing JavaScript directly in HTML, developers usually store JavaScript code in separate .js files.

            This is done using the src attribute of the <script> tag.

            Syntax
            <script src="filename.js"></script>
            4. Example of External JavaScript
            Step 1: Create a JavaScript File
            script.js
            function showMessage() {
                alert("External JavaScript file connected!");
            }
            Step 2: Link the File in HTML
            index.html
            <!DOCTYPE html>
            <html>
            <head>
                <title>External JavaScript</title>
            </head>
            <body>

            <button onclick="showMessage()">Click Me</button>

            <script src="script.js"></script>

            </body>
            </html>
            5. Advantages of External JavaScript Files
            Keeps HTML code clean
            Improves code reusability
            Easier maintenance
            Faster website loading using browser caching
            Better organization of code
            6. Placement of <script> Tag

            The <script> tag can be placed:

            Inside the <head> section
            Inside the <body> section
            Best Practice

            Usually placed before the closing </body> tag:

            <body>

            <script src="script.js"></script>
            </body>

4. Control Flow (If-Else, Switch) 

    Question 1: What is control flow in JavaScript? Explain how if-else statements work with an example. 

        In JavaScript, control flow refers to the order in which program statements are executed. It controls how decisions are made and how the program behaves under different conditions.

        Control flow allows a program to:

        Make decisions
        Repeat actions
        Execute different blocks of code based on conditions

        Common control flow statements include:

        if
        if-else
        switch
        Loops (for, while)
        if-else Statement in JavaScript

        The if-else statement is used to execute different blocks of code depending on whether a condition is true or false.

        Syntax
        if (condition) {
            // code executed if condition is true
        } else {
            // code executed if condition is false
        }
        How It Works
        JavaScript checks the condition inside if.
        If the condition is true, the if block runs.
        If the condition is false, the else block runs.
        Example of if-else
        let age = 18;

        if (age >= 18) {
            console.log("You are eligible to vote.");
        } else {
            console.log("You are not eligible to vote.");
        }
        Output
        You are eligible to vote.
        Explanation
        Variable age stores value 18
        Condition checked:
        age >= 18
        Since the condition is true, the if block executes.
        The else block is skipped.
        Example with False Condition
        let marks = 30;

        if (marks >= 40) {
            console.log("Pass");
        } else {
            console.log("Fail");
        }
        Output:
        Fail

     Question 2: Describe how switch statements work in JavaScript. When should you use a switch statement instead of if-else? 

        In JavaScript, a switch statement is a control flow statement used to execute one block of code from multiple possible options.

        It is commonly used when there are many conditions based on the same variable or expression.

        Syntax of switch Statement
        switch(expression) {

            case value1:
                // code block
                break;

            case value2:
                // code block
                break;

            default:
                // default code block
        }
        How switch Works
        The expression inside switch() is evaluated.
        Its value is compared with each case.
        If a matching case is found, that block executes.
        break stops further execution.
        If no match is found, the default block runs.
        Example of switch Statement
        let day = 3;

        switch(day) {

            case 1:
                console.log("Monday");
                break;

            case 2:
                console.log("Tuesday");
                break;

            case 3:
                console.log("Wednesday");
                break;

            default:
                console.log("Invalid Day");
        }

5. Loops (For, While, Do-While)

    Question 1: Explain the different types of loops in JavaScript (for, while, do-while). Provide a basic example of each.

        In JavaScript, loops are used to execute a block of code repeatedly as long as a condition is true. They help reduce repetition and make code efficient.

        The main types of loops are:

        for loop
        while loop
        do-while loop
        1. for Loop

        The for loop is used when the number of iterations is known.

        Syntax:
        for (initialization; condition; increment/decrement) {
            // code block
        }
        Example:
        for (let i = 1; i <= 5; i++) {
            console.log(i);
        }
        Output:
        1
        2
        3
        4
        5
        Explanation:
        i = 1 starts the loop
        Condition i <= 5 is checked each time
        i++ increases the value after each iteration
        2. while Loop

        The while loop runs as long as the condition is true. It is used when the number of iterations is not fixed.

        Syntax:
        while (condition) {
            // code block
        }
        Example:
        let i = 1;

        while (i <= 5) {
            console.log(i);
            i++;
        }
        Output:
        1
        2
        3
        4
        5
        Explanation:
        Condition is checked before each iteration
        If condition is true, loop runs
        If false, loop stops
        3. do-while Loop

        The do-while loop executes the code block at least once, even if the condition is false.

        Syntax:
        do {
            // code block
        } while (condition);
        Example:
        let i = 1;

        do {
            console.log(i);
            i++;
        } while (i <= 5);
        Output:
        1
        2
        3
        4
        5

    Question 2: What is the difference between a while loop and a do-while loop? 

        In JavaScript, both while and do-while loops are used to repeat a block of code as long as a condition is true. However, they differ in when the condition is checked.

        1. while Loop

        A while loop checks the condition before executing the loop body.

        Syntax:
        while (condition) {
            // code block
        }
        Example:
        let i = 1;

        while (i <= 3) {
            console.log(i);
            i++;
        }
        Output:
        1
        2
        3
        Key Point:
        If the condition is false initially, the loop will not run at all.
        2. do-while Loop

        A do-while loop executes the code first, then checks the condition.

        Syntax:
        do {
            // code block
        } while (condition);
        Example:
        let i = 1;

        do {
            console.log(i);
            i++;
        } while (i <= 3);
        Output:
        1
        2
        3
        Important Difference Example
        while loop example:
        let i = 5;

        while (i <= 3) {
            console.log(i);
        }
        Output:

        (No output)

        Because condition is false initially.

        do-while loop example:
        let i = 5;

        do {
            console.log(i);
        } while (i <= 3);
        Output:
        5

6. Functions 

     Question 1: What are functions in JavaScript? Explain the syntax for declaring and calling a function.

         In JavaScript, functions are reusable blocks of code designed to perform a specific task. Instead of writing the same code again and again, we define a function once and use it whenever needed.

        Functions help in:

        Code reusability
        Better organization
        Easier debugging
        Reducing repetition
        1. Declaring a Function

        A function is created (declared) using the function keyword.

        Syntax:
        function functionName(parameters) {
            // code block
        }
        Example:
        function greet() {
            console.log("Hello, Welcome to JavaScript!");
        }
        Explanation:
        function → keyword used to declare a function
        greet → function name
        () → can hold parameters (input values)
        {} → contains the code to execute
        2. Calling a Function

        A function does not run automatically. It must be called.

        Syntax:
        functionName();
        Example:
        function greet() {
            console.log("Hello, Welcome to JavaScript!");
        }

        // Function call
        greet();
        Output:
        Hello, Welcome to JavaScript!
        3. Function with Parameters

        Parameters allow functions to accept input values.

        Example:
        function add(a, b) {
            console.log(a + b);
        }

        add(5, 3);
        Output:
        8
        4. Function with Return Value

        Functions can also return values using the return keyword.

        Example:
        function multiply(a, b) {
            return a * b;
        }

        let result = multiply(4, 5);
        console.log(result);
    
    Question 2: What is the difference between a function declaration and a function expression? 

        In JavaScript, functions can be created in two main ways:

        Function Declaration
        Function Expression

        Both are used to define functions, but they differ in syntax, behavior, and hoisting.

        1. Function Declaration

        A function declaration defines a function using the function keyword with a name.

        Syntax:
        function greet() {
            console.log("Hello!");
        }
        Example:
        greet();

        function greet() {
            console.log("Hello!");
        }
        Output:
        Hello!
        Key Features:
        Has a function name
        Can be called before declaration
        Fully hoisted
        2. Function Expression

        A function expression stores a function inside a variable.

        Syntax:
        let greet = function() {
            console.log("Hello!");
        };
        Example:
        let greet = function() {
            console.log("Hello!");
        };

        greet();
        Output:
        Hello!
        Important Rule (Hoisting Difference)
        Function Declaration (Hoisted)
        sayHi();

        function sayHi() {
            console.log("Hi!");
            
        }

    Question 3: Discuss the concept of parameters and return values in functions.

        1. Parameters in Functions
        What are Parameters?

        Parameters are variables defined in a function that act as placeholders for input values.

        They allow a function to work with different data each time it is called.

        Syntax:
        function functionName(parameter1, parameter2) {
            // code
        }
        Example:
        function greet(name) {
            console.log("Hello " + name);
        }

        greet("Rahul");
        greet("Aman");
        Output:
        Hello Rahul
        Hello Aman
        Explanation:
        name is a parameter
        "Rahul" and "Aman" are arguments (actual values passed)
        The function uses the parameter to print different results
        2. Multiple Parameters

        Functions can take more than one parameter.

        Example:
        function add(a, b) {
            console.log(a + b);
        }

        add(5, 3);
        Output:
        8
        3. Return Values in Functions
        What is a Return Value?

        A return value is the output that a function sends back after execution using the return keyword.

        Instead of just printing a result, the function gives back a value that can be stored or reused.

        Syntax:
        function functionName() {
            return value;
        }
        Example:
        function multiply(a, b) {
            return a * b;
        }

        let result = multiply(4, 5);
        console.log(result);

9. JavaScript Events 

    Question 1: What are JavaScript events? Explain the role of event listeners. 

        1. What are JavaScript Events?

        An event is any interaction or change that the browser can detect and respond to.

        Common Types of Events:
        Mouse events (click, double-click, hover)
        Keyboard events (keydown, keyup)
        Form events (submit, change)
        Window events (load, resize)
        Example of an Event:
        <button onclick="alert('Button clicked!')">Click Me</button>
        Explanation:
        onclick is an event
        When the button is clicked, the alert message is shown
        2. What is an Event Listener?

        An event listener is a function that “listens” for a specific event and executes code when that event occurs.

        Instead of writing events directly in HTML, we use JavaScript to handle them in a cleaner way.

        3. Role of Event Listeners

        Event listeners are used to:

        Detect user actions
        Separate HTML and JavaScript code
        Improve code organization
        Make web pages interactive and dynamic
        4. Syntax of Event Listener
        element.addEventListener("event", function);
        5. Example of Event Listener
        <!DOCTYPE html>
        <html>
        <body>

        <button id="myButton">Click Me</button>

        <script>
        document.getElementById("myButton").addEventListener("click", function() {
            alert("Button clicked using event listener!");
        });
        </script>

        </body>
        </html>
        Output:

        When the button is clicked:

        Button clicked using event listener!
        6. Explanation
        getElementById("myButton") selects the button
        addEventListener("click", ...) listens for a click event
        The function runs when the event happens
        7. Advantages of Event Listeners
        Can add multiple events to the same element
        Keeps HTML clean (no inline JavaScript)
        Better control over events
        Easier to maintain and debug
        8. Example with Multiple Events
        let btn = document.getElementById("myButton");

        btn.addEventListener("click", function() {
            console.log("Clicked!");
        });

        btn.addEventListener("mouseover", function() {
            console.log("Mouse over button!");
        });

10. DOM Manipulation 

    Question 1: What is the DOM (Document Object Model) in JavaScript? How does JavaScript interact with the DOM?

        1. What is the DOM?

        The DOM is a tree-like structure created by the browser when it loads an HTML page.

        Each part of the HTML document becomes a node in this tree:

        Elements (tags)
        Attributes
        Text content
        Example HTML:
        <html>
        <body>
            <h1>Hello</h1>
            <p>Welcome</p>
        </body>
        </html>
        DOM Representation:
        Document
        └── html
            └── body
                ├── h1 → "Hello"
                └── p  → "Welcome"
        2. Why is the DOM Important?

        The DOM allows:

        Dynamic updates to web pages
        Interaction with user input
        Real-time content changes without reloading the page
        3. How JavaScript Interacts with the DOM

        JavaScript interacts with the DOM using built-in methods and properties.

        It can:

        Select elements
        Change content
        Modify styles
        Add or remove elements
        Handle events
        4. Selecting DOM Elements
        Example:
        document.getElementById("title");
        document.querySelector("p");
        5. Changing Content
        document.getElementById("title").innerHTML = "New Heading";
        Explanation:
        Selects element with id title
        Changes its content
        6. Changing Styles
        document.getElementById("title").style.color = "blue";
        7. Adding Event Listeners (DOM Interaction)
        document.getElementById("btn").addEventListener("click", function() {
            alert("Button clicked!");
        });
        8. Adding New Elements
        let newPara = document.createElement("p");
        newPara.innerText = "New paragraph added!";
        document.body.appendChild(newPara);

    Question 2: Explain the methods getElementById(), getElementsByClassName(), and querySelector() used to select elements from the DOM.

        | Method                     | Selects                    | Returns        | Example            |

11. JavaScript Timing Events (setTimeout, setInterval) 

    Question 1: Explain the setTimeout() and setInterval() functions in JavaScript. How are they used for timing events

             1. setTimeout()
            What it does:

            setTimeout() runs a function once after a specified delay (in milliseconds).

            Syntax:
            setTimeout(function, timeInMilliseconds);
            Example:
            setTimeout(function() {
                console.log("Hello after 3 seconds");
            }, 3000);
            Output (after 3 seconds):
            Hello after 3 seconds
            Explanation:
            Function waits for 3000 ms (3 seconds)
            Then executes only once
            Useful for delayed actions
            Real-life uses:
            Showing pop-up messages after a delay
            Loading screens
            Delayed notifications
            2. setInterval()
            What it does:

            setInterval() runs a function repeatedly at fixed time intervals.

            Syntax:
            setInterval(function, timeInMilliseconds);
            Example:
            setInterval(function() {
                console.log("Hello every 2 seconds");
            }, 2000);
            Output:
            Hello every 2 seconds
            Hello every 2 seconds
            Hello every 2 seconds
            ...

            (continues until stopped)

            Explanation:
            Executes repeatedly every 2000 ms (2 seconds)
            Runs continuously until stopped using clearInterval()
            3. Stopping setInterval()
            let id = setInterval(function() {
                console.log("Running...");
            }, 1000);

            // Stop after 5 seconds
            setTimeout(function() {
                clearInterval(id);
            }, 5000);

     Question 2: Provide an example of how to use setTimeout() to delay an action by 2 seconds

            Example: Delay an Action by 2 Seconds
        setTimeout(function() {
            console.log("This message appears after 2 seconds");
        }, 2000);
        Output (after 2 seconds):
        This message appears after 2 seconds
        Explanation:
        setTimeout() schedules the function to run later
        2000 milliseconds = 2 seconds
        The function executes once after the delay
        The message is printed after 2 seconds
        Example with Alert (Browser)
        setTimeout(function() {
            alert("Hello! This appears after 2 seconds");
        }, 2000);

12. JavaScript Error Handling 

    Question 1: What is error handling in JavaScript? Explain the try, catch, and finally blocks with an example
    
            1. try Block

            The try block contains the code that might cause an error.

            Example:
            try {
                let result = 10 / 0;
                console.log(result);
            }
            2. catch Block

            The catch block runs if an error occurs in the try block. It handles the error.

            Example:
            try {
                let x = y + 10; // error: y is not defined
            } catch (error) {
                console.log("An error occurred: " + error.message);
            }
            Output:
            An error occurred: y is not defined
            Explanation:
            Error occurs in try
            Control moves to catch
            Error message is displayed instead of crashing program
            3. finally Block

            The finally block always runs, whether an error occurs or not.

            Example:
            try {
                console.log("Trying code...");
                let x = 5 + 5;
            } catch (error) {
                console.log("Error occurred");
            } finally {
                console.log("This always runs");
            }
            Output:
            Trying code...
            This always runs

    Question 2: Why is error handling important in JavaScript applications? 

        1. Prevents Application Crashes

        When errors occur (like undefined variables or invalid operations), error handling ensures the program continues running instead of stopping completely.

        Example situation:
        User submits a form with missing data
        Without handling → app crashes
        With handling → error message shown, app continues
        2. Improves User Experience

        Error handling allows developers to show friendly error messages instead of technical crashes.

        Example:
        try {
            let x = y + 10;
        } catch (error) {
            console.log("Something went wrong. Please try again.");
        }

        ✔ Better for users than showing raw system errors

        3. Helps in Debugging

        Error handling provides useful error information that helps developers identify and fix problems quickly.

        Example:

        error.message shows what went wrong
        Makes debugging easier and faster
        4. Maintains Program Flow

        Using try, catch, and finally, JavaScript ensures that even if one part fails, the rest of the program can still run.

        Example:
        try {
            console.log("Task 1");
            let a = b; // error
        } catch (error) {
            console.log("Error handled");
        }

        console.log("Task 2 continues");
